# Architecture Memlog: Aine POC

## Metadata

- **scope:** Full-stack todo application
- **purpose:** Consistency contract for frontend, mock API, and localStorage persistence
- **altitude:** System (all boundaries between major units)

## Constraints (from PRD)

- Learning project; clean foundation, no enterprise complexity.
- React frontend + mock API + localStorage; no real backend for v1.
- Responsive web app; desktop and mobile via CSS breakpoints.
- Professional tone; instant feedback on all user actions.
- Core features: create, view, complete, delete todos.
- localStorage schema: todos keyed by UUID, each with description, completed status, createdAt.

## Major Decisions

### Paradigm & State Management
- **2026-09-01 | decision** — Component-driven React with unidirectional data flow (AD-1). State in components or Context; no Redux.
- **2026-09-01 | decision** — localStorage is single source of truth; UI derived from it (AD-2). All mutations write to localStorage first, then update UI.
- **2026-09-01 | decision** — Mock API layer exposes async CRUD interface between components and localStorage (AD-3). Components never touch localStorage directly.

### Data & Persistence
- **2026-09-01 | decision** — localStorage schema: todos keyed by UUID, each with id, description, completed, createdAt (AD-4). Single key "aine-todos".
- **2026-09-01 | decision** — Error handling: quota exceeded → clear oldest todos & retry; corrupted data → reset to empty list (AD-6).

### Responsive & Components
- **2026-09-01 | decision** — Single codebase, CSS media queries for responsive design. Breakpoints: 640px (mobile), 1024px (tablet/desktop). Touch-friendly 48px+ tap targets (AD-5).
- **2026-09-01 | decision** — Minimal component tree: App, TodoList, TodoItem, TodoForm. Each has single responsibility (AD-7).

### Styling & Build
- **2026-09-01 | decision** — Tailwind CSS for styling (confirmed by user).
- **2026-09-01 | assumption** — Vite as build tool.

### Final Confirmations
- **2026-09-01 | decision** — React component state ONLY; no Context API, Redux, or Zustand (confirmed by user).
- **2026-09-01 | assumption** — Mock API returns data instantly (no latency simulation).

## Events

- **2026-09-01 | event** — Architecture spine finalized. User approved; moving to epics & stories.
